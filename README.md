# Madison para Android — testes

[**Baixar o APK para Android**](https://github.com/MarcosBarrosMB/madison-android-testes/releases/download/teste-2026-10-21/Madison-teste-2026-10-21.apk)

Android 8.0 ou mais recente · aproximadamente 15 MB · processadores de 32 e 64 bits.

## Instalação

1. Abra o link no celular Android e baixe o arquivo `.apk`.
2. Abra o arquivo e toque em **Instalar**. Se solicitado, permita a instalação por essa fonte.
3. Abra o Madison e entre com sua conta institucional.

Se já usa o Madison no iPhone, entre com a mesma conta.

Versão de testes atualizada em **21/10/2026**, com assinatura de desenvolvimento verificada. O APK foi instalado e aberto em Android 13 e Android 17.
